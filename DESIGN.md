# Between: design contract

An editorial dating laboratory, with warm paper, ink typography, tomato-red actions, and lilac/olive accents. The first screen is the usable fictional cohort, not a marketing landing page. A distinctive pair of overlapping circles represents two independent perspectives.

Primary job: inspect a person's source-backed profile, watch their agent negotiate a date, then compare ranked connections. Navigation follows that order. Every participant and source is visibly fictional. Generated geometric portraits avoid implying a real identity.

Target viewports: 1440x900 and 390x844. Three-column desktop roster becomes one column on narrow screens. Keyboard focus, labeled controls, accessible dialogs, reduced motion, and touch targets are required.

States: loading shows analysis stages; empty search offers reset; invalid sources explain supported inputs; partial analysis marks unspecified needs unknown; success opens the profile before ranking; permission state is not applicable because the simulation uses no external accounts or permissions. Browser storage failure must show an explicit notice.
